# 智慧工地可视化看板

面向工地现场的大屏可视化看板，深色科技风，1920×1080 设计稿自适应缩放。

## 运行方式

无需构建、无需联网（ECharts 已本地内置），直接用浏览器打开：

```
site-dashboard/index.html
```

或启动本地服务：

```bash
cd site-dashboard && python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 功能模块

| 模块 | 说明 |
|------|------|
| **项目进度甘特图** | 各工序计划时间线（蓝色虚线框）vs 实际完成线（彩色实条），滞后率 = 计划进度 − 实际进度：绿色正常 / 黄色滞后<10% / 红色滞后≥10%，红色虚线为今日线，悬停查看详情 |
| **施工人员定位** | 按标段（A/B/C/加工区）展示钢筋班、木工班、瓦工班、架子班当日出勤人数与实时分布，定位点每 4 秒模拟流动；下方为班组出勤堆叠统计与出勤率 |
| **重大危险源监控** | 1#/2# 塔吊吊重、风速、回转角度实时仪表盘（2 秒刷新），附力矩/幅度/高度/司机信息；超限（吊重>8t、风速>12m/s）自动报警、面板红色闪烁并模拟拍照取证，照片可点击放大 |
| **环境监测** | PM2.5、噪声、扬尘 PM10 实时曲线与限值线；超标时卡片红色预警，并联动喷淋系统自动开启（地图喷淋点动画 + 状态灯），回落至限值 90% 以下稳定后自动关闭 |
| **实时报警记录** | 塔吊/环境/联动三类报警流水，含时间、级别、抓拍照片，最新在上 |

## 演示说明

- 数据为前端模拟：约 18 秒触发首次塔吊吊重超限（报警+拍照），约 12 秒触发首次扬尘超标（预警+喷淋联动），之后每 40~45 秒随机注入演示事件。
- 甘特图基准日固定为 2026-09-19（`js/main.js` 中 `TODAY` 常量，可修改）。

## 目录结构

```
site-dashboard/
├── index.html          # 页面结构
├── css/style.css       # 深色大屏样式
├── js/main.js          # 全部交互与数据模拟逻辑
└── assets/echarts.min.js
```

## 对接真实数据

`js/main.js` 中各模块数据入口清晰，替换为接口轮询即可：

- 工序数据：`PROC` 数组
- 班组出勤：`PLAN` 对象 / `CREWS` 定义
- 塔吊数据：`cranes` 数组及 2 秒模拟定时器
- 环境数据：`env` 对象及 `envStep()` 函数
